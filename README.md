# QuantBlock — 個人投資家向けノーコード・アルゴリズム検証＆トレードSaaS

仮想通貨・FX・米国株・先物の個人投資家・デイトレーダー向けに、プログラミング不要で取引アルゴリズムを構築し、過去数年分のデータでミリ秒単位のバックテスト・金融工学リスク分析・コード出力・Webhook自動売買連携までを一気通貫で行えるFinTech SaaSプロダクトです。

## 主な機能

1. **ノーコード・ブロック接続型戦略ビルダー (`@xyflow/react`)**
   - マーケットデータ → 買い/売り条件ブロック → AND/OR論理ゲート → 執行＆リスク管理ブロックを視覚的に接続
   - SMA / EMA / RSI / MACD / ボリンジャーバンド / ストキャスティクス / 出来高 / 定数の自由な組み合わせ
   - 構築したロジックをリアルタイムに自然な日本語へ自動翻訳
2. **ミリ秒高速バックテストエンジン (`src/engine/`)**
   - 過去5年分（1,800本の日足 / 4時間足 / 1時間足）を 1〜3ms で検証
   - 損切り(SL)・利確(TP)・トレーリングストップ・レバレッジ・片道手数料(bps)・スリッページ(bps)を厳密反映
   - 独自OHLCV CSVファイルのアップロード検証にも対応
3. **プロ仕様チャート & 金融工学アナリティクス (`lightweight-charts`)**
   - ローソク足＋戦略インジケーター重ね描画＋BUY/EXIT/TP/SL矢印マーカー＋連動オシレーターサブチャート
   - 資産曲線 vs Buy & Hold、ドローダウン（水中グラフ）、月次リターンヒートマップ
   - シャープレシオ・ソルティノレシオ・カルマーレシオ・プロフィットファクター・期待値・最大DD算出
4. **クオンツラボ（金融工学 × 自動化）**
   - **2次元グリッドサーチ・パラメータ最適化ヒートマップ**（クリックで最適パラメータを戦略へ即適用）
   - **1,000回モンテカルロ・ブートストラップ分析**（95%信頼区間ファンチャート・DD30%超破産確率算出）
   - **TradingView Pine Script v5 / Python (Pandas)** ワンクリック自動コード生成＆ダウンロード
   - **Bybit / Binance / Discord Webhook** 自動売買シグナルJSON生成＆テスト送信
5. **SaaSマネタイズ基盤（Stripe決済対応）**
   - Starter (¥0) / Pro (¥9,800/月) / Quant (¥29,800/月) の料金プランUIとバックエンドAPI
   - `.env` に `STRIPE_SECRET_KEY` を設定するだけで本番Stripe Checkoutサブスクリプション決済へ自動接続（未設定時はローカルデモ決済モードで動作）

## ローカル起動方法

```bash
# 依存パッケージインストール
npm install

# 1. APIサーバー起動（Stripe Checkout / WebhookテストAPI）
npm run server

# 2. 別ターミナルでフロントエンド起動
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

## テスト・ビルド

```bash
# バックテスト＆金融工学エンジンの検証
npm run test:engine

# TypeScript型チェック + 本番ビルド
npm run build
```
